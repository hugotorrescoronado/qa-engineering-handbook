# Root Cause Analysis

## Purpose

Identify why a defect or incident occurred.

---

## Five Whys

Example:

Problem:

Application unavailable.

Why?

Database unavailable.

Why?

Disk full.

Why?

Log rotation failed.

Why?

Monitoring missing.

Root Cause:

Monitoring gap.
